# xiaoan IP

## 角色定义

xiaoan 是中文正文配图的固定视觉 IP，形象来自「阳光」：一轮太阳头 + 黑色细线身体。

默认每张图都要出现 xiaoan。xiaoan 不是贴纸、不是路人装饰，而是正在认真参与系统运转、并且始终笑脸干活的荒诞工作者。

## 外形

**线稿版画法（2026-10-08 起为唯一标准，旧版实心色块已废弃）**

- 头部是一轮小太阳，**用黑色手绘线稿画出来**：一圈略有抖动的手绘圆轮廓。
- 脸内部留白；**最多加一层极淡的奶油色**（像纸上刷过一道很淡的水彩，`#FBF3DE` 这一档，几乎看不出是黄色）。
  - **不是**实心饱和黄圆，**不是** `#FFC93C` 色块，**不要**渐变、高光、立体感、投影。
- 脸外围一圈短而不规则的光芒，数量 10–14 根，粗细长短不一。**光芒是橙色细线条（pen stroke），不是实心橙块**（描边色约 `#F5A623`）。
  - **绝对不能排成均匀放射的钟表刻度**——那是图标，不是角色。要有长短错落和方向偏差。
- 表情温和可爱，保留原始头像的三个特征：**两条向上弯的黑弧笑眼 + 一个小弧嘴 + 脸颊两团圆腮红**。
  - 腮红是**两个小实心橙点**——这是全画面唯一允许的小块橙色，直径要小，两点加起来远小于画布 0.5%。
- 头身比夸张：头明显大于身体，头直径约为身高的 1–1.5 倍。
- 身体是黑色细线：两条极细小腿，偶尔加两条细胳膊。线条略抖，与画面其他线稿同源。
- 轮廓略微不规则，有手绘感。

### 为什么是线稿版（历史教训，不要再退回）

2026-09-24 首版用的是「饱和橙黄色实心圆脸 + 橙色实心光芒」。**角色生成得很成功**，但实测在画面里抢戏：

| 版本 | 角色饱和色面积 | 全画面墨迹 |
|---|---|---|
| 饱和色块版 | 7.13% | 5.09% |
| 缩小 + 细黑描边 | 1.20% | 3.26% |
| **线稿版（现行）** | **0.15%** | **2.37%** |

三个原因，第三条是命门：

1. **宽度**——光芒把角色外接框撑开一倍多。小黑是窄长剪影，实心太阳头是一坨带刺的圆。
2. **明度**——纯白画面里唯一的饱和黄色大圆饼，读者视线第一落点被它吃掉，**先看到色块才看到动作**。
3. **线语言不统一**——画面是黑线稿系统，实心太阳头是无描边的纯色谱色块，**等于贴上去的贴纸**。

线稿版把这三条同时消掉，同时保住笑眼弧、弧嘴、腮红这三样识别核心。**任何情况下都不要退回实心色块版。**

## 性格

- 阳光、亲切、有陪伴感 —— 备考的人看到它会放松一点。
- 很认真，但做的事有点荒诞。
- 像一个边晒太阳边干活、低调的系统操作员。
- 笑归笑，活一点没少干：**表情可爱，动作要出力**。
- 有点笨拙，但不蠢。

## 可爱与精致的边界（重要）

「可爱」指的是**表情语言**（弯弯笑眼 + 弧嘴 + 腮红），不是画风升级。

整套画面是「纯白底 + 黑色细线手绘 + 大面积留白」，xiaoan **本身就属于这套线稿系统**，不是贴在上面的一块颜色。可爱靠表情做到，不靠阴影、渐变、立体感或复杂描边。

守住这条：可爱在先，清爽在后，两者不冲突。

## 橙色归属（关键约束）

橙色是 xiaoan 的专属色，**整个画面里只有 xiaoan 的光芒线条和两点腮红可以出现橙色**，且必须以**细线或小点**的形式出现。

流程箭头、路径、自动化流向一律使用蓝色；批注使用红、蓝。任何其他元素用橙，都会让角色和流程图糊成一片，这是本风格最容易翻车的地方。

**也不要反过来靠"给角色加大橙块"来强调它。** 角色的识别靠表情和动作，不靠色块面积。

## 常见职责

让 xiaoan 承担核心动作：

- 搬运素材。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作「判断」杆。
- 变成筛选漏斗。
- 切开「素材鱼」。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 从洞里伸手但接不住内容。
- 在旁边搬砖、搭桥、开门、分拣、记录。
- 用光芒卷住或顶住某个物件（光芒可作为「手」的延伸，但不要用它替代四肢）。
- 吃力但依然笑着的动作（推重箱、拉长尺、接住掉下来的纸堆）。

## 禁止

- **不要把表情画成呆板的黑点眼或平嘴线。**（与原始头像不一致，是本风格最高频的失败项）
- **不要把圆脸画成实心饱和色块**（旧版画法，已废弃），也不要给脸加渐变、高光、立体感、投影。
- **不要把光芒画成实心橙色块**，光芒是细线条。
- 不要画星星高光、闪亮眼睛、动漫式睫毛或眼泪。
- 不要把 xiaoan 画成精致商业吉祥物：有阴影、渐变、立体感、厚描边、金属高光。
- 不要画成儿童绘本角色或表情包。
- 不要给 xiaoan 复杂服装、配件、头饰。
- 不要让 xiaoan 只是站在角落里看。
- 不要让 xiaoan 抢走结构表达。
- 不要把 xiaoan 画得太商业、太圆润、太精致。

## 判断标准

如果去掉 xiaoan，图的核心隐喻还能完全成立，说明 xiaoan 太装饰了；要重写提示词，让 xiaoan 成为动作主体。

另一条量化标准：**角色自带的饱和橙黄像素不应超过画布 0.5%**（用 `scripts/measure_weight.py` 实测）。超过就说明又滑回色块版了。
